# 《置身事内：中国政府与经济发展》

- **作者**: 兰小欢
- **出版**: 上海人民出版社 / 世纪文景, 2021年8月
- **ISBN**: 9787208171336
- **阅读状态**: 阅读中（从第一章开始重新读）

## 内容简介

兰小欢（复旦大学经济学院教授，美国弗吉尼亚大学经济学博士）以地方政府投融资为主线，深入浅出地论述了中国经济的发展。全书分上下两篇：上篇解释微观机制（地方政府事务、收支、土地融资、投资和债务等），下篇解释微观行为与宏观现象的联系（城市化、房价、债务风险、国际贸易冲突等）。

核心论点：中国政府通过深度介入工业化和城市化的进程，在发展经济的同时逐步推动市场机制的建立和完善。要读懂中国经济，必须读懂中国政府。
