# 分税制改革、土地财政与政策时滞

> 触发：读第二章，围绕分税制改革与土地财政展开两轮讨论
> 日期：2026-08-30

## 对话记录

用户看到分税制改革这块，让我简单介绍什么是分税制，然后回答我抛的两个钩子。

**分税制改革是什么**：把中央和地方原来"包干"的关系，改成"分税"——按税种划分谁收什么。改革前（1985—1993）是"财政包干制"，像包工头模式：每个省每年上缴固定数额，剩下的全归自己。出两个毛病：一是"两个比重"往下掉（中央收入占全国比重跌到 1993 年约 22%，发达国家一般 50% 以上），中央穷到要跟富裕省份借钱；二是地方"藏富于企业"——先给企业减税、再用摊派收费把钱捞回来，国家税基被掏空。

1994 年朱镕基推分税制，把税按种类拆开：增值税中央 75% 地方 25%，2001 年所得税再中央 60% 地方 40%，消费税归中央、营业税归地方。效果是中央财政汲取能力恢复了。关键点：**税权上收，事权没跟着上收**——地方还是要花钱，钱却少了，这个缺口就是土地财政的导火索。

**用户对反事实的判断**：土地出让权也归中央 → 极其中央集权，对地方不利。土地牵扯直接的基本利益，这块利益被中央牢牢绑住，地方政府就没有足够权力去掌控经济和民生。我的回应：方向对，1994 年是一套组合拳——中央拿走"存量"（增值税 75%），地方留下"增量"（土地收益全归地方），于是地方想富就得不停制造新东西。土地留给地方本质不是给"权力"，是给"搞增量的胡萝卜"。

**第二轮，用户抛三个核心问题**：① 不卖地就没别的办法搞经济吗？② 是分税制导致了土地财政吗？③ 政策到经济有时间差，有没有现在的政策会影响到多年后的民生？

**① 一定要卖地吗**：不卖地也有别的路——税收分成（细水长流）、转移支付（只够保运转）、收费罚款（不可持续）、借债（城投举债，本质和卖地一样是透支未来）。但卖地是这几条里激励最强、来钱最快、体量最大的那个：土地是政府垄断的、能资本化抵押融资、一次性拿一大笔、还跟 GDP 政绩绑定。所以不是"只能卖地"，而是在"分税制缺钱 + 政府垄断土地 + 地方要出政绩"这套约束下，卖地是激励最强的选项，地方自然扑上去。卖地和借债本质都是"寅吃卯粮"——把未来收益提前变现。

**② 分税制导致土地财政吗**：重要推手但不是唯一原因，警惕单因决定论。分税制只制造了"缺口"（推力），土地财政还要凑齐：土地国有（能力）、1998 住房商品化（需求释放）、2002 招拍挂（地价市场化）、城镇化加速（地价飙升）、GDP 考核（拉力）。是多因撞在一起的结果，不是分税制一手造成。当年把土地出让权留给地方只是谈判折中，没人预见它后来成命脉。

**③ 政策时滞**：1994 分税制到 2015—2016 房价暴涨隔了二十年——1994 分税制 → 1998 住房商品化 → 2002 招拍挂 → 2008 四万亿（第一波）→ 2015—2016 棚改（第二波）。顺着这个逻辑，现在时滞最长的政策：房地产长效机制（房地产税会让地方从"卖地"转向"持有收税"，转型要十几年；保障房十年后才松动"必须买房"的观念）、人口政策（生育+延迟退休+养老金，决定二十年后的劳动力和你我老年的日子）、产业政策（新质生产力/科技投入，5—10 年见分晓，决定这代人的就业结构和城市格局）。

**方法论沉淀**：看现在的政策，别问"眼下解决了什么"，要问"塑造了谁的激励、什么时候、以什么形式显形"。分税制当年只是"解决中央缺钱"的应急措施，没人想到二十年后长成那样。

**第三轮，用户追问概念与历史细节**：① 什么是增值税、税种有哪些、为什么说它在生产环节征收、什么是第三产业？② 卖地难道不是透支未来、国家允许无限卖地吗？③ "土地出让权留给地方"——谈判前难道归中央？

**① 概念澄清**：增值税（VAT）对流转中"增值的部分"征税，靠"销项税 − 进项税"的抵扣链条实现，每个环节只缴自己新增价值的税。税种按对象分：流转税（增值税/消费税/关税）、所得税（企业/个人）、财产税（房产税/契税/土地相关税）、行为税、资源税；按归属分中央税/地方税/共享税（增值税 1994 年中央 75% 地方 25%，2016 营改增后调为 50:50）。**修正前面笔记的不准确说法**：增值税不是"只在生产环节征"，而是贯穿生产到销售每个环节，但税基跟着"产值/销售收入"走、与本地生产规模挂钩——这才是地方拼命招商搞工业的原因。第三产业即服务业（第一产业农业、第二产业工业+建筑业）。

**② 卖地透支未来 + 约束**：双重透支——存量资源一次性变现（一块地只卖一次 70 年使用权）+ 靠推高地价房价滚雪球（透支未来居民收入与财富）。国家不允许无限卖地，约束是事后逐步加上的：18 亿亩耕地红线、建设用地指标、土地用途管制与规划、招拍挂、收支两条线（2006）、房住不炒（2016）、三道红线（2020）、土地出让金划转税务征收（2021）。90 年代到 2010 年代约束松、地方冲动强，2010 年代后期才层层收紧。

**③ 土地出让权历史（重要修正）**：谈判前不是"全归中央"，而是中央地方分成——1988 年城镇土地使用税五五分成，1989 年国务院 38 号文规定土地出让金中央 40% 地方 60%（财政部细化后中央约 32%），但地方瞒报少交、中央实际拿得少。1994 分税制作为平衡地方财力的让步，把土地出让金全部留归地方。所以"留给地方"是"从中央参与分成变成全归地方"，是收益分配让渡，不是所有权转移（土地所有权一直在国家）。

**第四轮，用户对书中一句话不解**："虽然企业可以层层抵扣，最终支付税金的一般是消费者……但因为增值税在生产环节征收，所以地方政府更加关心企业所在地，而不是消费者所在地。"用户自己举了例子：河南生产、出厂价 500，上海销售 1000，消费者付 1000，疑惑"为什么最终支付税金的是消费者"。

**拆解**：用户是两个困惑叠在一起——① 把"交税"和"承担税"混为一谈；② 以为税是 500 和 1000 之间那笔"差价"。

**① 1000 块里到底多少税**：1000 是**含税价**，本身就是"货款 + 税"打包的，不是额外再缴。拆开（13%）：货款 885 + 增值税 115 = 1000。所以税是 115 不是 500，500 和 1000 的差是"加价"（渠道成本 + 利润），与税无关。中国面向消费者的报价习惯是含税价（价签不写税），美国是标价外加税，体感差别很大——这是普通人困惑的来源。

**② 这 115 怎么交上去的**：

| 环节 | 不含税价 | 销项税 | 进项税 | 实缴 | 缴在哪 |
|------|---------|--------|--------|------|--------|
| 河南工厂 → 上海经销商 | 500 | 65 | 0（简化） | 65 | 河南 |
| 上海经销商 → 消费者 | 885 | 115 | 65 | 50 | 上海 |
| 合计 | | | | **115** | |

链条上所有企业实缴之和 = 115 = 消费者付的税。**企业是过路财神**——钱从消费者手里经企业账上过一手到税务局，企业自己一分没掏。买原料付的进项可抵扣，卖货收的销项是向下游收的，进销一抵差额交掉。

**③ 为什么"最终由消费者承担"**：消费者是链条终点站，没法再往下转嫁。企业全部能转嫁（进项抵扣 + 向下游加价收回）。这是**税负归宿（tax incidence）**——法律上企业申报缴纳，经济上消费者承担，两者分离。

**④ 为什么"地方政府关心企业所在地"**：税缴在哪，钱归哪。115 里 65 落河南、50 落上海，**跟谁消费无关，跟企业注册/销售地有关**。上海消费者买河南货，生产环节 65 块归河南；若经销商注册在河南（如网购直发），上海一分拿不到，但上海人的钱花出去了。所以地方理性选择是**抢企业不抢消费者**。

**⑤ 书里那句的准确含义**："增值税在生产环节征收"是通俗简化——严格说生产、批发、零售每环节都征。准确说法是：**增值税按"生产地原则"归属，不按"消费地原则"归属**。

**⑥ 诚实的补充**：理论上"完全转嫁"，现实中抵扣链条会断（小规模纳税人开不了专票、利息不可抵扣、在途库存垫付税的资金成本），税负会部分沉淀在企业身上。"企业完全不承担增值税"是理想模型。

**⑦ 钩子（接第三轮的政策时滞）**：学术界这几年在推增值税地方分成从"生产地原则"改"消费地原则"（谁消费钱归谁），若真改了，地方激励会从"拼命招商搞生产"转向"服务居民、促进消费"。**"地方拼命抢企业"这个现象，根子就在这条归属规则上**——和分税制一样，一条技术性规则塑造了几十年政府行为。

**第五轮，用户一次抛五个问题**：① 什么是过剩产能行业，明知过剩还推不是纯内卷吗？② 开票链路是这样吗？③ 跨省抵扣 90 年代就认吗？④ 美国的销售税制度跟中国有何区别？⑤ 专票和普票区别？为什么小规模开不了专票？为什么利息不能抵扣？

**① 过剩产能**：生产能力 > 市场能消化的需求。典型行业：钢铁、水泥、平板玻璃、电解铝、煤炭、船舶、光伏。**"全国过剩"≠"本地过剩"**——每个地方都想"我建了能抢别人份额，不建别人也会建"，典型**合成谬误（fallacy of composition）**。且退出极难：贷款来自国有银行（系统性风险）、地方给土地电价担保、关停=失业+坏账+财政减收。所以"去产能"等于自断一半财路。和"明知不可持续还卖地"同一逻辑——个体理性在错误激励结构下就是继续加码。

**② 开票链路**：用户理解正确。**每手交易都开票**，同一张票对开票方是销项税、对收票方是进项税。整条链（原料商→河南工厂→上海经销商→消费者）每手都开，票串起来就是增值税链条。**所以增值税死依赖发票系统**——没票不能抵，链条就断。中国搞金税工程三十年就是管票，90 年代**虚开增值税专用发票是死刑罪**，2011 年刑法修正案（八）才取消（一次性取消 13 个经济犯罪死刑）。

**③ 跨省抵扣**：**认，1994 年就全国统一**。要拆两件事：抵扣规则全国统一（不管票从哪个省来）vs 收入归属按缴纳地分省。上海经销商拿河南票抵扣没问题，只是最后实缴的 50 归上海、工厂交的 65 归河南。**抵扣全国统一，分钱按省来分**。1994 分税制同时推行增值税的重要目的就是打破地方保护主义——抵扣链条本身就是打通全国市场的钥匙。

**④ 美国销售税（关键对照）**：

| | 中国增值税（VAT） | 美国销售税（Sales Tax） |
|---|---|---|
| 立法层级 | 中央统一 | 州+地方，各搞各的 |
| 征收环节 | 生产、批发、零售每环节 | 只在最终零售环节 |
| 抵扣 | 有 | 没有 |
| 税率 | 全国统一 13%/9%/6% | 州级 2.9%–7.25%，加地方最高约 10.25% |
| 钱归谁 | 中央地方共享 | 归征收的州/地方 |
| 体感 | 含税价，无感 | 标价外加税，有感 |

美国销售税归**消费发生地**，所以美国地方政府关心消费者和零售业（招商场、抢人口、拼学区），中国地方抢工厂（增值税归生产地）。**"地方抢企业不抢消费者"不是天然的，是税制规则的产物**。5 个州不收州级销售税（俄勒冈、蒙大拿、新罕布什尔、特拉华、阿拉斯加）。2018 年 South Dakota v. Wayfair 判决后远程卖家达门槛也需代收。

**⑤ 专票 vs 普票**：区别只一条——专票可抵扣、普票不可。派生区别：专票要完整税号信息、只开给有抵扣需求方、对个人消费者/免税项目/集体福利不得开专票。

**小规模纳税人开专票**：说法已过期——2016 年试点、2019 年扩大、**2020 年 2 月全国全面放开**。历史原因：小规模走**简易计税**（按征收率 3%，2023—2027 减按 1%，全额计税不抵进项），**不在抵扣链条里**。硬接会卡壳：下游只能抵 1%/3%，但其上游（若为一般纳税人）已按 13% 交过，中间那截沉淀成重复征税。根本原因：它不是链条一环，接上去链条也是断的。

**利息不能抵扣**：财税〔2016〕36 号规定购进的**贷款服务**进项不得抵扣（同样不得抵的还有餐饮、居民日常服务、娱乐服务）。核心原因：**存款利息不征增值税**，而存款涉及千万储户、开票无法操作，链条在"存款"这端就断了；一头断，另一头也不能开否则国家净损失。其他原因：存款征税会砸到储户、利率是宏观调控工具（抵税会扭曲加息降息效果）、防"息转费"（36 号文连带把与贷款直接相关的顾问费手续费咨询费也划入不得抵扣）。结果：企业融资成本含一笔不能抵扣的税，是"融资贵"的制度来源，金融业在增值税体系里成了封闭孤岛。

**本轮的线**：从"过剩产能"到"专票利息"，一路摸到同一件事——**税制规则决定政府行为、企业行为和最终经济形态**。过剩产能是增值税+GDP考核逼出来的，地方抢工厂是生产地原则逼出来的，融资贵是抵扣链条断裂逼出来的。制度不是背景板，是发动机。

## 要点提炼

- 分税制 = 把"包干"改成"分税"，中央拿走增值税 75% 等大头；税权上收、事权没跟上，是土地财政的导火索
- 卖地不是唯一手段，但是"分税制缺钱 + 土地垄断 + 政绩考核"约束下激励最强的选项；本质是寅吃卯粮
- 土地财政是多因叠加（分税制 + 土地国有 + 住房商品化 + 招拍挂 + 城镇化 + GDP 考核），不是分税制一手造成
- 政策到经济有巨大时滞：1994 分税制 → 2015 房价暴涨，中间二十年，每一步都在蓄力
- 看政策的方法：问"塑造了谁的激励、什么时候显形"，而不是"眼下解决了什么"
- 修正：土地出让权历史是"从中央参与分成（1989 年中央 40%）变成全归地方"，是收益分配让渡，不是所有权转移；增值税也不是"只在生产环节征"，而是税基与生产规模挂钩
- 企业是"代收代缴"的过路财神——法律上企业缴税，经济上消费者承担（税负归宿分离）
- 消费者付的含税价里已含税（1000 = 885 货款 + 115 税），企业实缴之和恰好等于这笔税
- 增值税按"生产地原则"归属，所以地方"抢企业不抢消费者"；改"消费地原则"是学界改革方向，会改变地方激励
- 过剩产能不是地方"蠢"——"全国过剩≠本地过剩"，合成谬误 + 退出成本高，是激励结构逼出来的内卷
- 抵扣规则全国统一，收入归属按省分；1994 年增值税本身就是打破地方保护主义的工具
- 美国销售税归消费地 → 美国地方官抢的是商场和人口，中国地方官抢的是工厂。行为差异来自规则差异，不是文化差异
- 专票/普票只差"能否抵扣"；小规模纳税人 2020 年起已可自开专票；利息不得抵扣的根因是存款利息不征税、链条在存款端就断了
